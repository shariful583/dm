# Lanes browser extension: privacy policy

The Lanes extension for Chrome and Edge connects your browser to the Lanes Download Manager
desktop app on the same computer.

**What it reads.** When a download starts, or when you use a Lanes button or menu item, the
extension reads the download's address, file name, size and type, the page it came from, your
browser's user-agent string, and the cookies the browser holds for that address. It notes which
video and audio files and streaming playlists the current tab loads, so it can list them.

**Where it goes.** All of this is passed only to the Lanes app on your computer, through the
browser's native-messaging connection, so Lanes can download the file the way the browser would.
Nothing is sent to the Lanes developers or to any other server. The extension has no analytics,
no tracking and no advertising.

**What is kept.** Your extension settings are stored by the browser (and synced by it if you
use browser sync). The list of detected media is kept only while the tab is open. The Lanes app
keeps cookies and passwords in memory only for the downloads that need them; it never writes
them to its files.

**Questions.** Lanes is open source (GPL-3.0-or-later); the code is in the project repository.
Please open an issue there.
